## What is this?

Cresco Family is a free, **fictional** financial-learning experience. A Child practices choices; a Parent explores boundaries and exact one-time decisions; both can learn together. There are **no real accounts, investments, transfers, prices or legal guardian checks**.

**Open [VERIFIED_PUBLIC_FAMILY_URL] and tap “Try Cresco - no sign-in”.** No registration, private invite, password, wallet or access code is required. One person can switch between both simulated profiles in the same browser. All progress resets on refresh.

## Try it — about 5–8 minutes, or explore freely

1. **Child:** Open **Learn** and complete any short lesson. In **Home**, choose a saving goal and set aside 20 pretend credits.
2. **Child:** Open **Explore**, search a fictional business, compare examples, and read a research question. Try the 25-credit **MKT** fictional choice; the initial Key should block it and create a specific request.
3. **Parent (simulated):** Switch to **Parent view**, open **Requests**, and review the **exact** fictional amount, asset and limit. Try **Approve once** or **Decline**. This does not verify that you are anyone's parent.
4. **Child:** Switch back. If you approved, retry the exact MKT practice choice and see its receipt/portfolio consequences; approval must not be reusable a second time. If you declined, observe the refusal and explore other actions. Optionally open **Learn Together**.

You can stop anytime. **Do not enter real personal or financial details.** If a child participates, please explore together with an adult.
