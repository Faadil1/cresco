# CRESCO for the Crypto World's Fair

Status on 2026-10-12: **live on Solana Devnet**, submitted to Colosseum's Crypto World's Fair.
This folder is the single home of the World's Fair work. It replaces the separate
`cresco-worlds-fair` repository, which is kept only as a pointer.

**CRESCO lets someone act alone with money that is not fully theirs, inside limits enforced by a
Solana program, while the person responsible approves one exact exception without changing the rules.**

| | Family | Delegated capital |
|---|---|---|
| Sets the limit | Parent | Allocator, fund, DAO treasury |
| Acts alone inside it | Teenager | Strategy, trading bot, AI agent |
| Watches | Second parent | Risk owner |

Same program, same mandate, same exception flow; only the words change. CRESCO started as the family
experience (Stocklana); the World's Fair work generalized its on-chain mechanism.

> "What I find exciting about CRESCO is the ability to approve one exact exception without widening the
> agent's standing mandate. Through my work on Sanction, I recognize how much that boundary matters, and
> I'm excited about CRESCO's opportunity to carry that control all the way through to execution."
> Eric Lovold, founder of Sanction (quoted with written permission, 2026-10-12)
